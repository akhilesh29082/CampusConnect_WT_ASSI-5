# CampusConnect — WT Assignment 5
Requires Node.js 20+ (prefer 22 LTS). Open this folder in VS Code. Run `npm install`, `npm test`, `npm run dev`. Open the local URL shown. `npm run build` creates dist; `npm run preview` previews it.

Deploy: create a GitHub repository, commit and push this folder (excluding node_modules and dist). On Render create a Static Site, connect the repo, use build command `npm install && npm run build` and publish directory `dist`. Open the generated URL and test blank submission, invalid entries and valid submission. Capture screenshots and record the URL in your report. No database or backend required. This is a demonstration, not real registration.
